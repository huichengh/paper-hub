# 论文汇总与对比平台

上传 PDF → 自动解析元数据 → 按大类归类 → 表格化汇总 → 勾选任意论文并排对比 → **全屏检阅加批注** → 多维筛选 → 导出 Excel。

**在线体验**：https://huichengh.github.io/paper-hub/

## 功能

- **上传**：点选或把 PDF / 整个文件夹拖到页面任意位置，支持批量
- **自动解析**：读 PDF 前 8 页，提取题目、作者、年份、文献类型、期刊/学校、学位授予单位、学科专业、导师、关键词、摘要、页数
- **自动分类**：期刊论文 / 硕士论文 / 博士论文 / 会议论文 / 研究报告 / 专著，左侧栏按类计数
- **表格**：点表头排序，点行内「编辑」可改任意字段
- **筛选**：关键词全文、作者、期刊/学校、专业、导师、标签、相关度、年份区间、页数区间、分类，条件可叠加
- **对比**：勾选任意 2 篇以上，逐字段并排，绿色 = 各篇一致，黄色 = 有差异
- **检阅模式**：点行内「检阅」进入全屏阅读，**选中正文任意文字即可加批注**，支持重点/方法/结论/疑问/待引用五类标记；右侧栏可按类型筛选、搜索、编辑、删除、跳转；批注可一键汇总写入该文献的「备注」字段，或导出为 Excel
- **导出**：全库导出 Excel、对比表导出 Excel/CSV、JSON 备份下载与恢复

## 技术

纯前端，零后端、零联网依赖：

- [pdf.js](https://mozilla.github.io/pdf.js/) 4.10.38 — PDF 文本提取
- [SheetJS](https://sheetjs.com/) 0.20.3 — Excel 导出

两个库都已下载到 `docs/vendor/`，页面不请求任何外部资源。所有解析与计算都在你自己的浏览器里完成，PDF 内容不会上传到任何服务器。数据存浏览器 localStorage。

## 解析准确度

在 9 篇中文 PDF 上实测：

| 字段 | 命中 |
|---|---|
| 题目 / 作者 / 文献类型 / 关键词 / 页数 | 9/9 |
| 年代（支持中文数字年份） | 9/9 |
| 学科专业（兼容 4 种叫法） | 8/9 |
| 导师（兼容 4 种叫法，区分校内/合作导师） | 7/9 |
| 期刊/学校 | 7/9 |
| 摘要 | 8/9 |

**识别不准的原因**：各校封面字段标签不统一（同一含义有四五种写法，如专业有「学科专业」「专业名称」「专业领域」「专业学位领域」），且部分学校不印「学位授予单位」标签。解析器采用「多别名匹配 → 逐页降级查找 → 机构名正则兜底」三层策略，仍有少量字段需人工确认。

边界情况（界面可手动修正）：

- 扫描件 / 图片版 PDF 无文字层，提取不到内容，会明确列为「无法解析」
- 少数英文文献的导师字段会带入单位名残留
- 封面只印学院未印大学时，来源会显示为学院名

## 修改解析规则

`docs/parser.js` 里每个 `pick*` 函数负责一个字段，均有注释与别名列表。

中文 PDF 提取出的文本有两个怪癖：一是中文逐字带换行空格、全角数字逐位分离（"论 文 提 交"、"２ ０ ２ ０ 年"），因此解析器同时维护 `squeeze()`（保留换行，用于分行判断）与 `flatten()`（压平空白，用于标签匹配）两个视图；二是字段标签因校而异，每个字段都配了一组别名正则逐个尝试。改动时不要丢掉这两层。

## 检阅模式实现要点

批注能精确回跳，靠的是**锚定**而非存页码：

1. 用 pdf.js 的 `getTextContent()` 拿到每个文本片段的坐标，在 canvas 上叠一层"透明但可选中"的文字层
2. 用户选中文字时记录 `[页码, 片段索引, 起止偏移]` + 选中文本
3. 重绘时按锚点把对应片段包进 `<mark>`，因此不受分页和缩放影响

`Range` 定位必须用**文本节点**而非元素 + 字符偏移——因为 span 内可能已包着 `<mark>`，元素级偏移语义会错。

## 声明

本项目为个人学习用途的文献管理工具。解析结果基于 PDF 文本层的规则匹配，可能存在误差，引用前请核对原文。
